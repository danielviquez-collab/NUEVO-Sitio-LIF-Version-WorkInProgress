ranking, formularios, seguridad, compilacion y limites. `AGENTS.md` exige
actualizarlo junto con cada cambio. Las notas historicas locales no sustituyen
la guia vigente ni se duplican en este paquete.

Limites: no se comprobo Safari/iPhone fisico, trafico concurrente elevado ni
un nuevo envio real completo a todos los formularios. No se garantiza ausencia
total de fallos de Internet. Antes de lanzamiento comercial se requieren prueba
humana del journey, derechos de medios, privacidad, backups restaurables,
monitoreo y prueba de carga del adaptador Supabase actual.
